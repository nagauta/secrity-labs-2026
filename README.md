# secrity-labs-2026 — セキュリティ学習ラボ

IPA「[安全なウェブサイトの作り方](https://www.ipa.go.jp/security/vuln/websecurity/about.html)」で
解説される主要な脆弱性を、**インターネットから隔離された Docker 環境**で再現する教材です。
攻撃の仕組みを手を動かして理解し、同時に「どう直すか」も学びます。

実装言語は **TypeScript**（target は Hono、attacker は Node 標準モジュール、どちらも `tsx` で実行）。

## ⚠️ 安全のための大前提

- **ローカル隔離**: 公開ポートは `127.0.0.1` のみにバインド。外部ネットワークへは出しません。
- **教育目的のみ**: 意図的に脆弱なアプリです。本番・公開サーバには絶対に置かないこと。
- **自分の環境だけが対象**: ラボ内の自分のコンテナ以外を攻撃する用途には使いません。
- DVWA / OWASP WebGoat / Juice Shop と同じカテゴリの、定番の学習用やられアプリです。

## 構成

| コンテナ | 役割 | 公開先 |
|----------|------|--------|
| `target`   | Hono 製のやられ役Webアプリ（`/account` に危険な操作ボタン） | `127.0.0.1:8080` |
| `attacker` | おとりページ `evil.html` を配信する静的サーバ | `127.0.0.1:9090` |

両コンテナは Docker ネットワーク `labnet` に属します。

## モジュール1: クリックジャッキング

### 起動

```bash
docker compose up --build
```

### 攻撃を体験する

1. ブラウザで `http://localhost:9090/` を開く → 攻撃者の「おとりページ」。
2. 「プレゼントを受け取る」を押す。
3. 実際には裏に透明で重なった標的ページの「全ポイントを寄付する」が押され、
   ポイントが寄付されてしまう。
4. `http://localhost:8080/account` を直接開くと、残高が 0 になっていることを確認できる。

> 💡 仕掛けを目で見たいときは `attacker/evil.html` の iframe の
> `opacity: 0` を `0.3` に変えると、透明な標的ページがおとりボタンに
> 重なっている様子が見えます。ボタンの重なり位置は `top` / `left` で微調整します。

### なぜ成立するのか（脆弱点）

`target` の `/account` が、フレーム化を禁止するレスポンスヘッダ
（`X-Frame-Options` も `Content-Security-Policy: frame-ancestors`）を
**一切返していない**ため、任意の外部サイトから `<iframe>` で埋め込めてしまいます。
該当箇所は `target/server.ts` の `/account` ハンドラとその上のコメントを参照。

### 対策

`target/server.ts` 冒頭にコメントアウトされている `app.use(...)` を有効化すると、
以下のどちらか（両方でも可）が全レスポンスに付与され、攻撃が成立しなくなります。

- `X-Frame-Options: DENY` — iframe 埋め込みを全面拒否（古くからある専用ヘッダ）
- `Content-Security-Policy: frame-ancestors 'none'` — 祖先フレームを一切許可しない（現代的な方法）

有効化して `docker compose up --build` で再起動し、同じ手順で攻撃が
**失敗する**（iframe がブロックされ、おとりボタンを押しても何も起きない）ことを確認してください。

### 学習後のリセット

```bash
curl -X POST http://localhost:8080/reset
```
