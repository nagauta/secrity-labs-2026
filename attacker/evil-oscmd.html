🛠 つなぐ 運営ツール

サーバ疎通確認（ping）。対象ホストを入力して実行します。

サーバ疎通確認(ping)

↑ 本来はホスト名だけのはずが、; cat /etc/passwd を混ぜると ping のあとに任意コマンドが実行されます。 


    


    

      
🎯 攻撃者の狙い（OSコマンドインジェクション / Shellshock 2014）

      
    
        
  1. 管理ツールの入力が、最終的にシェルコマンド文字列に連結されていることに気づく。
    2. 
        
  2. ; や && でコマンドを継ぎ足し、/etc/passwd の閲覧や設定ファイルの窃取を行う。
    3. 
        
  3. さらにリバースシェルを仕込んでサーバを乗っ取り、内部ネットワークへ侵入する。
    4. 
        
  4. Shellshock では同じ「入力がシェルに届く」構図で、世界中のサーバが一斉に狙われた。
    5. 
      

    


    

      
🛡 対策した場合（シェルを介さない + 入力検証）

      
execFile('ping', ['-c','1', host]) のようにシェルを使わず引数配列で渡せば、
         ; や && はメタ文字として解釈されず、ただの文字列になります。
         あわせて /^[A-Za-z0-9.-]+$/ などで入力を検証するのが根本対策です。
