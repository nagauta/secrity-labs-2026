🔐 つなぐ 会員ログイン

教育用デモ。各ボタンは標的(localhost:8080)の応答を新しいタブで開きます。

① 認証バイパス（成りすまし）

ユーザー名欄に admin'-- を入れると、パスワード照合がコメントで無効化され、パスワード不要で admin としてログインできます。

② UNION でデータ窃取

会員検索に ' UNION SELECT ... -- を注入すると、本来見えない平文パスワードや秘密メモまで吸い出せます。

http://localhost:8080/sns/members?name=' UNION SELECT id, username||':'||password, email, secret FROM members --

🎯 攻撃者の狙い（SQLインジェクション / Sony Pictures 2011）

  1. ログインや検索の入力が SQL文字列にそのまま連結されていることに気づく。
  2. ユーザー名に admin'-- を入れ、パスワード条件をコメントアウトして成りすまし。
  3. 検索に UNION SELECT を注入し、会員の平文パスワード・秘密メモを一括窃取。
  4. 流出アカウントを他サービスへ使い回し（パスワードリスト型攻撃）してさらに被害が拡大する。

🛡 対策した場合（プレースホルダ）

WHERE username = ? AND password = ? のようにプレースホルダで値を渡せば、 入力は必ず「ただのデータ」として扱われ、admin'-- や UNION は SQL として 解釈されません。文字列連結をやめることが根本対策です。
