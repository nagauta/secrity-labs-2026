http://localhost:8080/sns/search?q=<script>alert(...)</script>

🎯 攻撃者の狙い（蓄積型XSS / Samy ワーム 2005）

  1. 攻撃者サミーが、自分のプロフィールのひとことに <script> を仕込む（つなぐが入力を無エスケープで保存・表示するため成立）。
  2. その profile を見た利用者のブラウザで script が動き、利用者本人として拡散投稿に「いいね」してしまう。
  3. さらに script は利用者自身のひとことにも同じ script を複製する。
  4. その利用者の profile を見た別の人へ…と自己増殖し、MySpace の Samy ワームと同じ構図で一気に広がる。
  5. 応用すると document.cookie 窃取やセッション乗っ取り、ページ改ざんにも使える。

🛡 対策した場合（出力エスケープ / CSP）

標的が出力時に < などを &lt; へエスケープすれば、 ひとことや検索語はただの文字列として表示され、script は実行されません。

Content-Security-Policy: script-src 'self' を併用すると、 インラインスクリプトや外部送信をさらに制限できます（多層防御）。
